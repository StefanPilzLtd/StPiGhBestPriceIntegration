# Contributing

Issues, feedback and pull requests are welcome. Fork the repository, create a branch and describe the problem, your change and the checks you ran. Contributions are provided under the MIT license.

Use disposable Shopware installations with synthetic data. Do not send real conversions to BestPrice or add undocumented APIs. Keep production entitlement checks intact; test adapters belong in tests/. Do not commit credentials, customer data, vendor/ or node_modules/.

See [development instructions](docs/development.md) and [current implementation status](docs/status.md).
